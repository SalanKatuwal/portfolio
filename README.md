# Salan Katuwal - Portfolio Website

Repository for my personal portfolio website, [salankatuwal.com.np](https://salankatuwal.com.np).

I'm Salan Katuwal, an Associate Software Engineer at **Bajra Technologies Pvt. Ltd.**, Kathmandu, Nepal, working as a **Python and Odoo Developer**. This site showcases my background, skills, and projects.

---

## 🌟 Features

- **Responsive Design**: Accessible on desktop, tablet, and mobile devices.
- **Interactive Sections**: Single-page navigation across About, Resume, Projects, Certificates, and Contact.
- **Project Highlights**: Descriptions, source links, and live demos of my work.
- **Certificates Gallery**: Showcases certifications earned through online courses.
- **Contact Information**: Easy access to connect via email, phone, or social platforms.
